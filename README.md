# Blender 2.79x (Extended) for Raspberry Pi 4 & 5

## 🌍 The Mission
This project is dedicated to compiling a special, highly optimized version of Blender 2.79 on Raspberry Pi 4 and 5 (specifically for Debian Trixie/Bookworm environments).

**Our primary goal is educational:** To contribute to providing a unique, accessible platform for children and young people all over the world. We want to empower them to learn Python coding, 3D design, 2D/3D animation, digital sculpting, and much more—all on a computer the size of a business card.

## 🚀 Quick Start (Installation & Build)

### Prerequisites
* Raspberry Pi 4 or Raspberry Pi 5
* Recommended OS: Raspberry Pi OS (Debian Trixie/Bookworm based)
* Internet connection (for cloning and downloading dependencies)

### Build Instructions
The build process is fully automated. The script detects your hardware (Pi 4 vs Pi 5) and RAM size to adjust compilation flags and core usage to prevent overheating.

1.  **Clone the repository:**
    Create a directory named `blender-git` in your home folder and clone the project there.
    ```bash
    mkdir ~/blender-git
    cd ~/blender-git
    git clone [https://github.com/ozreha/blender279x.git](https://github.com/ozreha/blender279x.git)
    ```

2.  **Run the Build Script:**
    Enter the directory and run the start script.
    ```bash
    cd blender279x
    ./start.sh
    ```
    *Note: If you encounter network interruptions, simply run `./start.sh` again.*

3.  **Wait:**
    Depending on your Raspberry Pi model and RAM, the compilation will take between **1 to 2.5 hours**.

4.  **Launch Blender:**
    Once finished, go up one level to the main directory (`~/blender-git`). You will find two launcher scripts:

    * `./hardware_gl_blender27.sh` (Recommended): Uses hardware acceleration.
    * `./software_gl_blender27.sh`: Uses software rendering. Useful if you encounter display artifacts in Grease Pencil perspective mode (slower, but surprisingly decent on Pi 5).

## 💎 What Makes "Blender 2.79x" Special?

This is not the standard official Blender 2.79b. It is based on a specific, now-archived branch (formerly known as `blender2.7`) used by the Blender Institute during the development of Blender 2.80.

* **Hybrid Core:** It features the classic 2.79 user interface but runs on the **Blender 2.80 core codebase**.
* **Performance:** Many dependency libraries have been upgraded to their latest compatible versions for better stability and speed.
* **The Game Engine Lives:** Unlike modern Blender versions, **Blender Game Engine (BGE)** is fully present and functional. It is a complete game engine inside a 3D suite, running on your Pi.
* **Rendering:** Eevee is not included. It uses the classic Blender Internal renderer and a highly optimized Cycles engine.

## ⚡ Performance & Optimizations

We have pushed the limits of the ARM architecture to make this run as smoothly as possible.

### 1. Intel to ARM Porting (SSE2NEON)
We utilized **Automated ARM Porting via Scripted Source Substitution**. By using `sse2neon.h`, we translated Intel intrinsic instructions into ARM NEON instructions, providing a massive boost in calculation speeds.

### 2. Embree on ARM
In the original source, Embree (Intel's ray tracing kernels) was disabled for ARM. We successfully enabled it. This results in up to **40% speed increase** in Cycles rendering, especially in complex scenes.

### 3. Python Optimizations
Python is compiled with `--enable-optimizations` and `--with-lto`. While this increases the build time, it provides a **8% to 30% performance boost** in Python script execution depending on the task.

### 4. Hardware Specific Flags
We apply specific compiler flags based on your CPU:
* **Raspberry Pi 4:** `-march=armv8-a+fp+simd+crc -mtune=cortex-a72`
* **Raspberry Pi 5:** `-march=armv8.2-a+fp+simd+crc -mtune=cortex-a76`

### 5. Smart Resource Management
The build script automatically manages CPU cores to balance speed and temperature/RAM stability:
* **1GB - 2GB RAM:** Uses 1 Core (1GB is untested, may fail).
* **4GB RAM:** Uses 2 Cores.
* **8GB+ RAM:** Uses 3 Cores (Leaves 1 core free for system responsiveness and thermal management).

## ⚠️ Notes & Limitations
* **System Specific:** The resulting build is **not portable/standalone**. It will only run on the system (or identical environment) where it was compiled.
* **Dependencies:** Some non-essential libraries that were notoriously difficult to compile on this architecture were skipped to ensure a stable core build.
